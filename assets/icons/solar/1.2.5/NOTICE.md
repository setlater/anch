# Solar icon assets used by Anch

- Icon set: Solar
- Author: 480 Design
- Source: https://www.figma.com/community/file/1166831539721848736
- Data package: `@iconify-json/solar` 1.2.5
- License: CC BY 4.0
- License text: https://creativecommons.org/licenses/by/4.0/

This directory contains the SVG glyphs selected for the Anch application.
Resources are organized by Anch's semantic names and colored at runtime.
Vector adaptations are noted below.

`close-linear.svg` adapts Solar `close-circle-linear`: it keeps the same
1.5-width, round-cap linear treatment while omitting the enclosing circle for
the compact toolbar close action.

`add-linear.svg` adapts Solar `add-circle-linear`: it keeps the same
1.5-width, round-cap linear plus mark while omitting the enclosing circle for
add actions that already provide their own button surface.
