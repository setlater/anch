# 安册手工验证场景

本文件只维护虚构资料、操作步骤与预期结果；已通过记录和未完成队列统一见 [路线图](../ROADMAP.md) 。下列条目按验证目标选择，不要求每台设备、每次验证全量重做，也不表示本次已执行。资料集是可复用的场景参考，不是首发必须逐台录满的数量配额。

首发设备范围限现有一加 3T 与一加 12，按实际系统、包类型及操作范围记录结果；其他厂商、平板、完整分屏／字号矩阵作为后续兼容性工作，规则见 [测试策略](testing.md#首发设备范围) 。未执行的安全检查仍保留未验证状态。

## 使用边界

本文件用于 `securityValidation` Debug APK 的内部人工体验，以及经授权的正式签名 Release 真机安全验收。正式包验收同样只使用虚构资料；安装成功不代表安全准入。所有姓名、编号、地址、机构和金额均为虚构测试数据，不对应真实个人或真实账户。

- 禁止替换为真实身份证号、银行卡号、保单号、地址或附件。
- 禁止录入支付密码、登录密码、验证码、CVV、私钥或助记词。
- App PIN 和备份密码由验证者现场设置，不写入本文件、截图或问题记录。
- 历史 V1 专项仅可在本地交互式终端运行 `fvm dart run tool/create_historical_v1_fixture.dart` 生成。临时密码必须隐藏输入且不记录；生成物只含虚构资料、不含附件，文件已存在时工具会拒绝覆盖。
- 以下日期以 2026-07-17 为验证基准；在其他日期验证时，应相应调整“已过期／即将到期／正常”三组日期。
- 行驶证当前不开放新建，不纳入本轮录入数据。
- 银行卡「账户类型」填写银行 App 或开户资料标示的Ⅰ类／Ⅱ类／Ⅲ类账户；不确定可留空。

## 验证前准备

### 产品展示取景

使用下方虚构成员与基础资料，按「成员整理 → 搜索 → 遮蔽详情与主动复制 → 附件 → 加密备份入口」录制短流程。首页展示归属与资料摘要，搜索展示匹配，详情展示字段分组与遮蔽，备份页展示数据出口。不得用静态样张冒充运行截图，也不以打开备份页代替恢复成功证据。

取景前核对设备上的资料均为明确的虚构展示数据；有未知资料时停止采集。仅通过现有前台屏幕保护设置允许截图，结束后恢复原偏好。密码、PIN、系统文件选择器路径、通知栏个人内容和剪贴板实际内容不进入画面。展示素材须标注虚构资料、实际版本和包类型；开发包另须说明开发验证状态，不冒充正式发行包画面。实际制作与验收状态只记录在路线图。

## 正式签名包应用锁验收

在已核对签名与哈希、只含虚构资料的正式包中执行。既有 PIN 和密码由验证者本人输入，不向检查者提供，不写入脚本、截图或报告。

用户明确委托自动验收时，可在确认尚无既有 PIN 的测试应用中，通过正常界面设置随机测试 PIN。测试 PIN 仅保留在驻留驱动进程内存中，不进入命令参数、文件、日志、截图或报告；不得读取、猜测或覆盖既有凭据。驱动仅记录静态页面断言、结果和耗时，遇到锁屏、应用失焦或断连即停止点按，并保留内存中的测试 PIN，直到可继续收尾。结束后通过正常重新认证关闭测试应用锁，恢复原有偏好，再释放内存。关闭应用锁仍保留加密的 PIN 校验材料，必须如实记录；后续可通过应用锁主开关设置个人 PIN。强生物识别成功仍须本人实际按压，不得模拟认证结果。

1. 在「设置 → 应用锁」设置独立的 6 位安册 PIN。确认设置页显示已启用；默认「每次回到安册时」下，按 Home 后返回须验证，输入正确 PIN 后正常进入。
2. 强制结束应用后重新启动，仍须验证；输入原 PIN 后可访问原有虚构资料。此项同时检查正常根节点的安全存储跨进程保持，空库启动不能替代资料及附件读取。
3. 连续输错 5 次进入冷却，冷却期间强制结束再启动，仍不能通过重启消除限制。停留在锁定页等待冷却自然结束，不再重启，确认错误提示消失、数字键恢复可用且正确 PIN 能解锁；累计失败的后续冷却按实际实现递增，不修改系统时间或校验材料。
4. 设备已有可用强生物识别时，验证者经重新认证开启「生物识别解锁」，检查成功、主动取消及退回安册 PIN。未录入或不可用时应明确提示并保留 PIN；不能把未出现认证框记为通过，不为验收录入或修改系统指纹。
5. 修改 PIN、关闭应用锁、切换「生物识别解锁」均先要求重新认证；取消后设置与原 PIN 保持。修改 PIN 后分别确认旧 PIN 拒绝、新 PIN 接受。忘记 PIN 只检查已有强生物识别恢复入口；未单独批准清空资料时，不执行删除本机资料。
6. 在资料详情和图片预览进入真实后台，返回后敏感字段应重新遮蔽、图片预览退出，并按当前自动锁定方式验证身份。最近任务保护通过系统窗口状态与实际任务预览分别检查；仅有 `FLAG_SECURE` 不代表已验收所有厂商的任务快照。
7. 在永久删除确认、备份失败明细及录入确认弹窗显示时进入真实后台，返回并触发应用锁后，弹窗内容和操作不得盖过 PIN 页，也不得执行原确认。正确解锁后可关闭或继续原流程；实际永久删除仅操作专门自建的可丢弃虚构资料，未获删除授权时只取消。恢复的已认证清单另须按后台清理规则关闭并要求重新选择文件。

每项只记录设备／系统、APK 哈希、通过或失败类别。无可用指纹、尚未完成实际 PIN 交互或尚无虚构附件时，明确标为未验，不用自动化夹具结果代替。获授权的测试 PIN 通过正式包正常界面验证时，应与内部夹具结果分别记录。
