# 安册隐私说明

更新日期：2026 年 11 月 10 日。本文适用于 setlater 提供的安册 Android 正式版 v1.0.0；本次更新将说明收回开源主仓库，不改变 App 的数据处理行为。

## App 处理的数据

你可以自行录入成员、联系方式、地址、证件与卡片编号、保险信息、日期、备注、图片和文件。这些内容只在当前设备上处理，并存入安册的应用私有目录；开发者不通过安册 App 收集、上传或共享这些资料。

当前正式版不申请网络权限，没有账号、云同步、广告、统计、崩溃上报、远程配置或在线 AI。开源不改变资料保存位置，也不意味着资料会发送到 GitHub。

## 权限与系统能力

- 生物识别由 Android 完成，安册只接收认证结果，不读取或保存指纹、人脸模板。
- 照片和文件由用户主动选择，安册不扫描整个相册或文件目录。
- Android 系统自动备份和设备迁移被禁用，不把应用私有数据交给系统自动备份。

## 用户主动带出资料

复制字段、保存图片到相册、使用其他应用打开附件或通过系统文件选择器导出备份，会把内容交给用户选择的系统组件或第三方应用。目标可能继续保存、同步或处理这些副本，适用其自身规则；安册不会自动执行这些操作。

「关于安册 → 查看最新版本」由系统浏览器访问固定的 GitHub 发布页，不携带本机资料或账号标识。App 不自行查询版本、下载或安装更新，离线帮助手册不需要访问网站。

## 保存、安全与删除

正式版资料库和附件在本机加密保存，导出备份使用用户设置的备份密码保护；安册不保存备份密码。安全措施有其适用边界，详见[安全设计](security.md)，不能代替系统锁屏、可靠设备环境和备份保管。

资料保留到用户永久删除、清空应用数据或卸载为止。「最近删除」中的资料在永久删除前仍保存在本机，没有自动清理期限。清空或卸载不会删除已导出的备份、保存到相册的图片、系统剪贴板内容或第三方应用取得的副本，这些内容需要在相应位置单独处理。

## 在线文档与第三方托管

用户说明、源码、下载与反馈统一由 GitHub 提供。浏览器访问 GitHub 时，GitHub 会按其[隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)处理请求相关信息；这些网页请求与安册 App 内的本机资料处理相互独立。

原帮助站停止独立内容维护。旧地址若保留兼容跳转，请求仍经过 Cloudflare，其处理适用 [Cloudflare 隐私政策](https://www.cloudflare.com/privacypolicy/)。旧网址不接收安册中的资料，不作为 App 帮助功能的依赖。旧站部署与退役历史由维护者归档，不在本仓库继续维护第二套帮助正文。
