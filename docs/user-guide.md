# 安册使用说明

本文适用于 Android 正式版 v1.0.0。App 内的「帮助手册」可离线阅读；下载与更新以 [GitHub Releases](https://github.com/setlater/anch/releases/latest) 为准，问题反馈使用[项目 Issues](https://github.com/setlater/anch/issues)。

## 开始使用

1. 在「成员」中添加自己或家人，再从首页「新增」选择资料类型。
2. 按页面提示填写资料并保存，通过首页、分类或搜索查找。
3. 中高敏字段默认隐藏，需要时主动查看或复制；不要仅凭列表摘要判断完整内容。
4. 重要资料录入后，及时导出加密备份，并保留至少一份手机之外的副本。

「家庭」指在同一台设备上按成员整理，不代表家人之间自动同步。安册没有账号或云同步，也不提供远程找回、远程擦除或自动异地备份。

## 备份与恢复

进入「设置 → 数据与备份」导出备份，设置并确认备份密码，在系统文件选择器中选择保存位置，等待导出成功。不要只因目标位置出现了文件就认定备份完整；中断或失败的文件不能作为可靠恢复来源。

当前默认导出为可移植的 V3 加密备份，资料和附件由备份密码保护。将备份文件与密码分开保管，至少保留一份不在当前手机上的副本。安册不保存备份密码，忘记后无法找回或重置。

恢复会用备份内容完整覆盖当前资料，不是合并。输入密码、核对恢复范围后再确认；需要保留当前资料时，先为当前内容另做一份备份。应用锁 PIN、生物识别偏好等本机安全设置不随备份迁移。

历史 V1／V2 备份保留识别与恢复兼容。无法安全恢复的历史附件会在覆盖前拒绝，不会跳过附件后报告成功。技术格式、校验及中断恢复机制见[备份格式说明](backup-format.md)。

换机时，先在旧手机导出最新备份，在新手机恢复并核对资料及附件，再处理旧手机。卸载或清空安册会删除其本机私有资料，不会替你删除已导出的备份。

## 应用锁与忘记 PIN

应用锁使用独立 PIN，可选择 Android 强生物识别。已开启且当前仍可用的强生物识别可以用于解锁或重设 PIN；否则，忘记 PIN 后只能确认清空本机资料，再恢复已有加密备份。

应用锁不能代替系统锁屏。手机丢失后，请使用系统提供的设备查找与保护能力；安册没有服务器可以替你找回资料。

## 安全使用与主动外发

正式版资料库和附件在本机加密保存，备份另由备份密码保护。这不代表能够抵御已被控制的系统或实时内存读取；安全机制及威胁边界见[安全设计](security.md)。

- 复制字段会把明文交给系统剪贴板。安册的后续清理不能阻止系统或其他应用在此之前读取。
- 保存图片到相册会产生安册之外的副本，系统云相册可能继续同步。
- 使用其他应用打开附件，会把内容授权给所选应用；操作前确认目标可信。
- 系统文件选择器中的保存位置可能由本机存储或第三方网盘提供，后续处理由对应服务负责。
- 「关于安册 → 查看最新版本」会主动打开浏览器；安册不自动检查、下载或安装更新，也不会在版本链接中附带本机资料。

不要保存支付密码、登录密码、动态验证码、CVV／CVC、私钥、助记词或其他可直接控制账户与资产的凭据。

## 常见问题

**安册会上传资料吗？** 当前正式版不申请网络权限，没有账号、云同步、广告、统计、崩溃上报、远程配置或在线 AI。用户主动外发及浏览器访问的边界见[隐私说明](privacy.md)。

**删除后能恢复吗？** 普通删除先进入「最近删除」，永久删除前可以恢复；最近删除没有自动清理期限。永久删除或清空本机资料后，无法在安册内撤销，既有外部备份也不会自动删除。

**为什么没有系统到期通知？** 当前只在应用内显示即将到期或已过期状态，需要定期打开安册查看。

**大附件操作为什么需要等待？** 读取、加解密和校验均在本机完成。请保持应用在前台，并确保设备及目标位置有足够空间；失败时按实际提示处理，不把未完成操作当作成功。
