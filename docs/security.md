# 安全设计

## 威胁边界

需要防护：

- 设备文件被普通方式读取。
- App 切后台、最近任务、截屏和录屏泄露。
- 列表、搜索、剪贴板和日志暴露高敏字段。
- 备份文件丢失后被离线破解。
- 忘记 PIN 后绕过前端锁访问数据。

不承诺防护已经完全控制设备、Root、恶意系统固件或正在运行时的高级内存取证。

## 数据库

`securityValidation` 与 `formal` 使用 SQLiteMC 文件数据库，密钥由本机安全存储管理。开发和测试的默认 `dev` 模式仍使用内存数据库；Release 无论是否传入安全模式参数，都强制进入 `formal`，不允许通过参数关闭加密或后台防窥。正式签名 Release 的真机安全走查、准入与发行状态以 [路线图](../ROADMAP.md) 为准。

正式路径要求：

- 数据库加密不可关闭。
- 缺少或损坏密钥时阻断启动，不能回退明文。
- 安全存储中已有的空字符串同样属于损坏配置，不得当作首次启动重新生成并覆盖。Android 安全存储出错时保留原存储并上报失败，显式禁用依赖的自动删除重试选项；资料重置只能经过应用既有的用户确认流程。
- 应用进程只创建一个数据库实例。
- schema 和迁移必须使用标准 Drift／SQLite 迁移，不修改 `sqlite_master`。

该自动删除默认项按实际锁定版本核对，依据见 [flutter_secure_storage 10.3.1 变更说明](https://pub.dev/packages/flutter_secure_storage/versions/10.3.1/changelog) 。应用显式覆盖错误恢复策略，不改变既有存储算法、密钥别名或资料加密格式。

## 附件

附件使用 AES-256-GCM，密文保存在应用私有目录。应用启动时从本机安全存储获取随机 32 字节主密钥，附件密钥由其独立派生；缺失或格式非法的密钥会阻断加解密，不会回退到固定开发密钥。

解密明文只在预览期间保留；图片预览只缓存当前页与最近查看过的一张，淘汰、解码失败、退出预览、应用锁定或进入后台时驱逐对应图片缓存并清零本类持有的字节。读取和解码完成前禁用保存，解码失败不输出原始异常或附件内容，可由用户主动重新加载；若失败的是缓存预览，同时移除对应的加密派生预览文件，清理结束后允许重试原图，下一次打开可重新生成预览。清理失败仍允许本次重试原图；不删除或改写原始附件。UI isolate 不得同步读取附件。

录入页和详情页的附件缩略图复用同一短生命周期组件；文件缺失、解密失败或组件替换时不得显示文件名、路径或底层错误。

## AppLock 与设备安全

AppLock 是应用访问控制，不等于数据库密钥。正式路径中：

- 数据加密始终开启。
- 后台遮罩和最近任务快照保护始终开启，不受前台截图偏好影响。Android 13 及以上使用 `setRecentsScreenshotEnabled(false)` 作为任务快照保护底线，允许前台继续按三档偏好截图；Android 12L 及以下在原生 `onPause` 临时启用 `FLAG_SECURE` 兜底，并在 `onResume` 恢复前台偏好。厂商任务列表的文案和占位外观由系统控制，应用不得依赖或伪造。
- 前台屏幕内容保护提供「仅保护敏感页面」「保护所有页面」「不限制」三档；默认采用「仅保护敏感页面」。
- 平台未确认所需保护生效前，敏感内容不显示、不接受焦点与操作。调用失败后保留明确的失败状态，由应用根隐藏原业务树并显示脱敏提示；重试确认成功后才恢复原页面状态，不能通过切换截图偏好绕过失败。异步队列忽略已过期请求，旧请求仍在执行时不把新页面视为已保护。
- 启动窗口保护失败时，在读取安全存储或创建资料会话前阻断；提示停止显示资料而不宣称平台保护已生效，允许重试，不清除本机资料。正式发行验证状态见 [路线图](../ROADMAP.md) 。
- 「仅保护敏感页面」按内容暴露程度判定：展示完整字段、附件明文或接收安全凭据的页面必须保护，至少覆盖 AppLock／PIN、资料录入编辑、资料详情、成员新增编辑、附件选择／裁剪／解密预览、备份密码、恢复预览和覆盖确认。
- 首页、成员列表、分类列表、搜索、到期、归档、最近删除等只展示低敏摘要的列表，以及普通设置、帮助、空白说明和不展示资料内容的数据管理入口可以截图；认为摘要同样敏感的用户应选择「保护所有页面」。
- 「不限制」只允许用户主动截屏或录屏前台内容，不得关闭应用进入后台后的最近任务快照保护；首次切换必须明确提示截图可能进入系统相册、云相册或第三方应用。
- Android 的 `inactive` 可能由通知栏、截图快捷方式或系统浮层短暂触发，不能单独改变前台 `FLAG_SECURE` 策略，否则会让「不限制」在部分厂商设备上仍无法截图；Flutter 的 `hidden／paused／detached` 只用于同步逻辑状态，最近任务保护必须先于该异步回调在原生生命周期生效。
- 屏幕内容保护偏好只保存在本机，不进入资料备份；缺失、损坏或无法读取时安全回退到「仅保护敏感页面」。
- 用户可以决定是否额外启用 AppLock；启用时必须先设置独立的 6 位数字安册 PIN，不能只依赖生物识别或系统锁屏密码。
- 应用锁启用状态只有记录缺失或有效的关闭值才按未启用处理；非缺失记录为空、格式／版本／字段非法或底层读取失败时必须报告配置异常。PIN 是否存在的读取失败也必须上抛脱敏异常，由启动门禁阻断，不能当成未设置 PIN 或已关闭应用锁。应用锁设置页读取失败时隐藏安全操作并提供脱敏错误及重试，加载成功前不得使用默认值更改安全配置；读取与重试不得改写凭据或清除资料。
- Android 生物识别只接受 `BIOMETRIC_STRONG`（Class 3）指纹或强人脸，不接受 Class 2 弱人脸，也不允许设备 PIN／图案／密码作为系统认证器回退。系统弹窗取消或不可用时回到安册 PIN。
- 自动锁定提供「每次回到安册时」与「重新打开安册时」两种模式，默认前者；后者仅在应用进程终止后的下一次启动要求验证。通知栏、系统弹窗和其他短暂 `inactive` 失焦不得触发锁定；系统生物识别弹窗引发的生命周期变化也不得误锁应用或覆盖后台防窥状态。
- PIN 连续失败达到阈值后按 30 秒、2 分钟、5 分钟递增冷却，失败次数和截止时间保存在本机安全存储并跨重启生效；冷却只限制 PIN，仍允许已启用的强生物识别。
- PIN 解锁在校验前先持久化本次尝试，验证成功后清除计数；中断或重启不会抹去已发起的尝试。冷却记录缺失视为首次使用，记录损坏或读取失败则阻断启动；运行中无法读写尝试记录时保持锁定，不执行 PIN 校验，提示重新打开安册，仍保留已启用的强生物识别入口。
- 关闭应用锁、修改 PIN、启用或停用生物识别前必须重新验证。忘记 PIN 时，仅当此前已启用的强生物识别验证成功，才允许重设 PIN；否则不能绕过锁，只能物理重置本机数据库、附件、PIN、应用锁状态与数据库密钥后重新开始或恢复外部备份。重置成功后由应用根节点移除旧组件树并重建资料空间，不复用已关闭数据库。

## 敏感字段

- 列表只使用低敏摘要。
- 搜索不长期缓存完整字段；银行卡尾号在数据库内匹配，仅返回资料 ID。仓储列表、搜索结果与卡片使用同一摘要投影，排除备注、原始 metadata 与诊断，字段值只保留账单日、还款日、有效期、保险截止日和长期有效标记；银行卡另保留低敏银行名称与注销标记，以分开展示机构和状态，不展示用途；保险另保留低敏险种，并从险种与截止日期重建摘要，不展示中敏保障对象或历史受益人、代理人、缴费日与保单状态。卡片没有全局资料缓存或测试专用 DTO。可识别的完整敏感号码和完整银行卡号输入在真实后台清空，普通关键词与短暂 `inactive` 不受影响。
- medium/high 字段默认遮蔽并独立展开。
- 进入后台、离开页面或锁定时重新遮蔽。
- 资料详情顶部敏感铭牌复制前进行明确确认，并且确认框只展示本次将复制的内容；下方字段行复制直接写入受控剪贴板并按既有策略自动清理，不展示确认框。
- 不在日志、异常、action trace、搜索索引或 snapshot 输出中记录真实字段值。

## 网络与权限

主清单不声明 `INTERNET`、相机、本地网络、存储、位置或麦克风权限；应用不接入广告、统计、崩溃上报、推送和远程配置。每次发布仍须审计最终 merged Manifest 和 APK，而不能只检查源码 Manifest。

「查看最新版本」只在用户点击后交由系统浏览器打开固定 HTTPS 页面，不携带本机资料或标识。应用不自行联网查询版本、下载 APK 或请求安装权限；网页内容与下载由浏览器处理。

## 正式准入条件

- 正式模式可运行且默认安全配置不可被编译参数意外关闭。
- 数据库、附件、备份和重置链路完成真机验证。
- 备份恢复失败不破坏现有数据。
- 所有敏感日志清零。
- 首发以现有一加 3T 与一加 12 的实际验证为设备范围，分别记录系统版本、包类型与检查结果；内部验证包的结论不得直接视为正式包验收。设备或厂商数量不作为准入门槛，其他厂商、平板及完整分屏／字号矩阵按后续兼容性工作推进。未验证的安全路径如实列出，不因缩小设备范围标为通过，具体证据与剩余准入项见 [路线图](../ROADMAP.md) 。
