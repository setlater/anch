## 素材来源

截图采集于 2026-10-26，设备为 PJD110，Android API 36，使用亮色主题与默认字号。图片为设备原始 PNG 截图，保留系统状态栏，未经裁剪、合成或内容替换。

运行包使用独立贡献者标识 `icu.codealive.anch.contributor`、本机开发签名与加密 `securityValidation` 模式。采集时已覆盖安装普通应用入口，临时数据填充入口已撤出。该 APK 的 SHA-256 为 `be07bfe2f3ecdcd6be981fd6faf97b05a77a1185f8fb6cb573f872081fb81cc8`。

虚构资料通过真实成员与录入页面保存，文本由本地临时夹具填入公开输入控制器，按钮通过原生触控执行。截图采集使用应用现有的前台截图设置，采集后恢复「仅保护敏感页面」。

## 展示与验证边界

本组截图对应的一加 12 三条虚构资料已通过真实导出页面、Android 文件选择器与恢复页面完成加密备份往返，恢复后资料和成员数量保持。银行卡查看、隐藏、确认复制，以及停留详情时的剪贴板自动清理也已验证。这组展示数据没有附件；后续一加 3T 正式候选已完成新附件导入、跨重启读取及独立安装备份恢复验证，详细范围见 [路线图](../../ROADMAP.md) ，不把该结果追记为截图采集包的验证。短视频尚未准备，不作首发前置条件。

这些画面用于说明交互和产品取舍。截图采集时项目处于开发验证阶段，尚未完成正式安全准入；该贡献者包只用于虚构资料，不用于真实敏感资料。后续 v1.0.0 已完成约定范围的工程安全准入并正式发布，但这组截图不作为正式发行包的验收证据。最新验证范围以 [路线图](../../ROADMAP.md) 为准，构建方式见 [贡献说明](../../CONTRIBUTING.md) 。
